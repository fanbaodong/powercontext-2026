# 验证样例

先按 README 初始化并运行 `python scripts/load_demo_data.py`。初始数据为两个项目、八篇演示笔记；五篇属于项目1“学习方法研究”，三篇属于项目2“认知科学笔记”。文档和段落ID由数据库分配，不要假设从1开始。

## 页面操作

| 步骤 | 输入/操作 | 预期结果 |
|---|---|---|
| 1 | 打开应用，选择“认知科学笔记” | 显示3篇演示文档 |
| 2 | 检索“间隔重复” | 包含《【演示笔记】间隔重复与记忆曲线》，有原段落与相关性分数 |
| 3 | 对其中一段点击“查看原文” | 打开同一资料，显示按序号划分的原文 |
| 4 | 状态改为“在读”，刷新再打开 | 状态仍为“在读” |
| 5 | 收藏命中段落，批注“用于设计复习计划” | 卡片包含资料名、段落及批注 |
| 6 | 编辑批注，再重复保存相同文字 | 均成功，无“卡片不存在”误报 |
| 7 | 导出Markdown | 包含原文、作者、批注、段落号与document/chunk定位ID；有来源URL的资料还包含URL |
| 8 | 切换到“学习方法研究” | 不显示项目2的卡片，旧检索结果清空 |

这些是演示数据的操作验证，不代表真实使用效果。真实应用截图、查询响应、导出样本位于 [evidence/](evidence/)。

## 可复制的HTTP检查

```bash
curl http://127.0.0.1:8036/api/health
curl http://127.0.0.1:8036/api/projects
curl -G --data-urlencode 'q=间隔重复' http://127.0.0.1:8036/api/search/project/2
curl 'http://127.0.0.1:8036/api/search/project/2?q='
```

前两项应返回数据库连接正常和项目列表。第三项 `total > 0`，至少一个结果的标题为上述“间隔重复”笔记；第四项返回空结果。全文自然语言模式可以匹配部分词，其他相关段落同时出现是正常行为。具体分数随文库内容变化，不硬编码。

## 自动验收

```bash
python -m pytest tests/ -q
python scripts/integration_test.py
python scripts/host_acceptance.py evidence/api-acceptance-local.json
```

真实数据库集成脚本检查导入、相同内容去重、跨项目独立保存、实际FTS、卡片、进度与无效输入；主机补充脚本检查HTTP边界、4线程并发导入及失败事务回滚。回滚测试故意让切块抛错，预期HTTP500且数据库无半成品，该日志不代表正常流程失败。

手动复查跨进程持久化：保存一张卡片与阅读状态，正常停止uvicorn，重新执行README启动命令，再查询原文与卡片；无需停止或清空数据库。
