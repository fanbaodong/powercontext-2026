# 研读台 · ReadTrace：Qoder 开发任务

本文由Codex整理需求与验收约束，尚不是功能实现或Qoder开发证据。主要设计、编码及后续修复交由实际登录的Qoder CLI完成，运行记录据实保存。

## 项目目的

为学习与科研解决“笔记分散、搜到结论却找不到原文、摘录后忘记阅读进度”的问题。实现本地单人资料工作台：导入资料 → seekdb全文检索 → 定位原段落 → 收藏带出处的证据卡片 → 保存阅读进度 → 导出带引用的Markdown笔记。数据必须跨浏览器刷新和后端重启持久化。

## 边界

- 工作区是本题powercontext/qoder，基于官方2026-competition-ecosystem；不要修改其它题目录或Git配置，不做commit/push。
- Python 3.10+、FastAPI、PyMySQL，单服务提供API与原生HTML/CSS/JS页面；依赖固定版本，无运行期云模型密钥，无需Node构建即可启动。
- seekdb是真实必需后端，不能退回SQLite/内存或伪造检索结果。部署只绑定loopback，单人本地模式；公网Qoder Sites只展示功能、真实截图、仓库与复现入口，不暴露数据库或本地API。
- 仅创建qoder_research专属库和本应用表，真实FULLTEXT索引，使用MATCH...AGAINST查询，并支持项目筛选。SQL全部参数化，固定标识符或严格白名单。
- 不读取任何.env真实文件、认证配置、浏览器Cookie或工作区外文件；配置示例仅占位值。不要使用或访问Qoder之外的个人账号。

## 功能

1. 创建/切换研究项目；项目数据相互隔离。
2. 粘贴资料，输入标题、可选作者、来源URL、标签；支持UTF-8 .txt/.md上传。按段落与长度切块并保存段落编号/内容hash；重复导入同项目相同内容幂等，跨项目独立。拒绝空文本、超限文件及不支持扩展名；不自动抓取外链。
3. 按关键字检索本项目原文，展示标题、作者、来源、原段落、段落编号、seekdb相关性得分。空查询显示提示，绝不伪称语义/向量检索。
4. 原文查看、证据收藏/取消、添加批注；卡片保存document_id/chunk_id和出处，Markdown导出包含标题、原文、批注、来源和段落号。
5. 每篇资料的“未读/在读/已读”进度及统计，刷新和重启保留。
6. 明确的空状态、加载中、错误提示；数据库不可用返回可理解错误，不伪装健康；导入后的最新原文立即可检索。
7. 原创演示数据，清楚标为演示笔记，不能伪造真实论文、用户数量、提效数据。准备至少8篇中文学习/科研方法短笔记，并给出固定可验证查询与期望出处。

## 界面

中文为主、清晰现代的双栏布局，深蓝侧栏/温暖纸白内容区/青绿色强调；桌面和手机均可用。左栏项目和统计，右侧文库、检索、证据卡片三页。所有导入内容以纯文本渲染，防止XSS；来源仅允许http/https安全链接并配置noopener。
